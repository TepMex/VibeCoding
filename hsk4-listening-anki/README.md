# HSK 4 Listening для Anki

Готовая колода: [скачать `hsk4-listening.apkg`](https://tepmex.github.io/VibeCoding/hsk4-listening-anki/hsk4-listening.apkg).

Колода содержит 509 карточек аудирования HSK 4:

- 110 заметок типа `HSK Listening TrueFalse`;
- 399 заметок типа `HSK Listening Choice`;
- 12 подколод по исходным тестам;
- встроенное перекодированное MP3-аудио для офлайн-повторения.

На лицевой стороне аудио запускается стандартным механизмом автопроигрывания Anki. Пользователь выбирает вариант и нажимает «Показать ответ». На обратной стороне подсвечиваются выбранный и правильный ответы, после чего пользователь сам выбирает оценку Anki.

## Сборка

Нужны Python 3.11+, `ffmpeg` и несколько гигабайт временного сетевого трафика для исходных WAV-файлов.

```bash
python3 -m pip install -r requirements.txt
python3 build_deck.py
```

Результаты:

- `dist/hsk4-listening.apkg`;
- `dist/hsk4-listening.report.json`.

Для быстрой проверки можно собрать только первые карточки:

```bash
python3 build_deck.py --limit 2
python3 -m unittest discover -s tests
```

JSON загружается из зафиксированной ревизии `5fe9a65173a4b9aa8aae7c513ea279b10bc64023` репозитория [Make-dream-clear/hsk4-mock-exam](https://github.com/Make-dream-clear/hsk4-mock-exam). Аудио скачивается по URL из JSON и преобразуется в моно MP3 48 кбит/с.

Тесты 13–19 содержат одну непрерывную запись секции без таймкодов отдельных вопросов. Эти вопросы, а также 10 вопросов из тестов 1, 3 и 7 без покарточной записи, намеренно не включены: повторять полную экзаменационную запись на каждой карточке было бы некорректно.
